# Backoffice

Esta carpeta contiene el panel interno del negocio.

- `index.php`, `login.php`, `panel_cocina.php` y `panel_delivery.php` son pantallas internas.
- `seccion/` agrupa modulos administrativos: menu, banners, ventas, compras, usuarios, etc.
- `templates/` contiene layouts del panel.
- `assets/` contiene CSS y JS del backoffice.
- `helpers/` contiene utilidades propias del panel.

Las URLs existentes siguen entrando por `/admin/...`.
