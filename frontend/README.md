# Frontend

Esta carpeta contiene la capa de presentacion.

- `customer/` contiene vistas, parciales y componentes del sitio publico.
- `backoffice/` contiene templates y piezas visuales del panel administrativo.

Los assets servidos por navegador siguen publicados en `public/assets` y `admin/assets`
para mantener compatibilidad con XAMPP y Apache. Si se agrega un proceso de build,
las fuentes deberian vivir aca y publicarse en esas carpetas servidas.
