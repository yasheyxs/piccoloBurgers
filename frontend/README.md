# Frontend

Acá va a vivir el sitio de los clientes como una aplicación independiente (HTML, CSS y JavaScript) que se comunica con el backend a través de una API.

Por ahora el sitio de clientes todavía se genera desde PHP y vive en `backend/`:

- Páginas: `backend/public/` (inicio, carrito, confirmar pedido, `cliente/`)
- Vistas y componentes: `backend/views/customer/`
- Estilos, scripts e imágenes: `backend/public/assets/` y `backend/public/img/`

La migración a esta carpeta está planificada en `docs/PROPUESTA_REESTRUCTURACION.md` (fases 2 a 4).
