# Panel de administración

- `index.php`, `login.php`, `panel_cocina.php` y `panel_delivery.php`: pantallas principales.
- `clientes*.php`: gestión de clientes y canje de puntos.
- `seccion/`: módulos del panel (menú, banners, ventas, compras, usuarios, pool, bebidas, etc.).
- `password/`: cambio y recuperación de contraseñas.
- `assets/`: estilos y scripts del panel.

Las plantillas (encabezado y pie) están en `../../views/admin/` y las utilidades en `../../src/Http/Admin/`.
